
This lab focuses on reading, parsing, and manipulating data stored in external text files using parallel arrays, custom static methods, formatted console output, and exception handling (`try/catch` blocks).


## Key Features & Methods

* **`readFile()`:** Reads player names and high scores from an input file (`playerdata.txt`) into parallel arrays using robust exception handling.
* **`displayPlayers()`:** Outputs the parallel arrays to the console in two aligned columns (`Player Name` and `High Score`) using `String.format()`.
* **`calculateAverage()`:** Computes and returns the average (double) high score of all players.
* **`selectionSort()`:** Implements a selection sorting algorithm to sort the parallel arrays in descending order by high score, ensuring names and scores stay synchronized.
* **`displayTopX()`:** Outputs the top `X` players and their corresponding high scores based on user-defined parameters.


## Technologies & Environment
* **Language:** Java
* **IDE:** IntelliJ IDEA
* **Concepts:** Parallel Arrays, Static Methods, File I/O (`Scanner` / `File`), Exception Handling, Selection Sort, Formatted Strings.
